## 分项 diff 结论

| 分项 | 本地 | 网关 | 说明 |
|---|---|---|---|
| completion $15/MTok | 计入 | 计入 | 基本一致 |
| prompt $3/MTok（未缓存） | **严重偏低** | 全量未缓存段 | pi 在 cache hit 时常把 input 记为 0，只留 cacheRead |
| input_cache_read $0.3/MTok | 计入但 token 偏少 | 按「输入×缓存%」 | 本地 cacheRead 计数 < 控制台输入×% |
| input_cache_write_5_min $3.75/MTok | **几乎未入账** | 有分项 | usage 常缺 cache_write 字段 |

**结论**：差额主因是 **usage 分项不完整 + 未缓存 prompt 漏计**，不是网关隐形加价（探针 management 费率与标价一致）。
