- 聚族顺序：仓库 → gold patch 的生产代码模块/文件 → issue 症状与 patch 机制。`+N/-N` 只计 gold `patch`（生产补丁），不计单列的 `test_patch`。
- 评级：**强**表示三题既有同类外部症状，也能从 gold patch 归纳出同一个可迁移的失误模式；**弱**表示路径紧邻且机制相似，但至少一题的外部症状或修复动作不够同质，作者若选应再复核。
- 难度感仅由 issue 复现范围、涉及状态数和 gold patch 大小估计，不是跑题结果。
